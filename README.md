# Aurora 博客系统

## 项目介绍
Aurora 是一个功能丰富、界面美观的现代化博客系统，采用前后端分离架构设计，提供完整的博客管理和用户交互功能。

## 技术栈

### 后端技术栈
- **Spring Boot 2.3.7** - 应用框架
- **Spring Security** - 安全框架
- **Spring AMQP** - 消息队列支持
- **Spring Data Elasticsearch** - 搜索引擎集成
- **MyBatis Plus** - ORM框架
- **Redis** - 缓存和数据结构存储
- **MySQL** - 关系型数据库
- **JWT** - 无状态认证
- **Knife4j** - API文档
- **Lombok** - 简化Java代码
- **Hutool** - Java工具包
- **Quartz** - 定时任务调度
- **Fastjson** - JSON处理
- **Commons-lang3** - 通用工具类
- **Sensitive-word** - 敏感词过滤

### 前端技术栈

#### 博客前台 (aurora-blog)
- **Vue 3 + TypeScript** - 前端框架
- **Element Plus** - UI组件库
- **Vue Router** - 路由管理
- **Vuex** - 状态管理
- **TailwindCSS** - CSS框架
- **Markdown-it** - Markdown渲染
- **ECharts** - 数据可视化

#### 管理后台 (aurora-admin)
- **Vue 2** - 前端框架
- **Element UI** - UI组件库
- **Vue Router** - 路由管理
- **Vuex** - 状态管理
- **Mavon Editor** - Markdown编辑器

## 面试相关问题及答案

### 1. 系统架构设计

**问题**: 请介绍一下Aurora博客系统的整体架构设计？

**答案**: 
Aurora博客系统采用前后端分离的架构设计。后端基于Spring Boot框架开发，主要包含以下几层：
1. **表示层(Controller)**: 处理HTTP请求，进行参数校验，返回标准化的响应数据
2. **业务层(Service)**: 实现核心业务逻辑，管理事务
3. **数据访问层(Mapper)**: 使用MyBatis Plus与数据库交互
4. **模型层(Entity/Model)**: 包含实体类和数据传输对象
5. **工具层(Util)**: 提供各种通用工具方法
6. **配置层(Config)**: 系统配置类，如Redis配置、安全配置等
7. **切面层(Aspect)**: 使用AOP实现日志记录、异常处理等横切关注点

系统集成了Redis作为缓存和数据结构存储，Elasticsearch提供全文搜索能力，Quartz实现定时任务调度，采用JWT进行无状态认证。

### 2. 安全机制设计

**问题**: 项目中如何实现用户认证和权限控制？

**答案**: 
1. **用户认证**: 
   - 使用Spring Security + JWT实现无状态认证
   - 用户登录成功后生成JWT令牌，后续请求携带令牌进行身份验证
   - 实现了TokenService接口，提供令牌的创建、刷新、解析等功能
   - 自定义UserDetailsService加载用户信息和权限

2. **权限控制**: 
   - 采用基于角色的访问控制(RBAC)模型
   - 自定义权限决策管理器和安全元数据源
   - 通过动态配置菜单和资源，实现灵活的权限管理
   - 接口级别的细粒度权限控制

3. **其他安全措施**:
   - 接口访问频率限制，防止暴力攻击
   - 敏感词过滤，保证内容安全
   - 密码加密存储

### 3. 缓存策略实现

**问题**: 项目中如何使用Redis进行缓存，解决了哪些问题？

**答案**: 
1. **缓存应用场景**:
   - 文章浏览量统计：使用Redis有序集合(ZSet)存储，文章ID作为成员，浏览量作为分数
   - 接口访问频率限制：使用Redis的incrExpire()方法实现
   - 热点数据缓存：缓存常用的分类、标签等数据
   - 用户会话管理：存储用户登录状态和权限信息

2. **解决的问题**:
   - 减轻数据库压力，提高系统响应速度
   - 实现高效的计数器和排行榜功能
   - 支持分布式部署场景下的数据一致性
   - 提供过期时间机制，自动清理不需要的数据

3. **缓存优化**:
   - 使用Jackson2JsonRedisSerializer和StringRedisSerializer进行序列化
   - 设置合理的缓存过期时间
   - 实现缓存预热和缓存更新机制

### 4. 性能优化措施

**问题**: 项目中采取了哪些性能优化措施？

**答案**: 
1. **缓存优化**:
   - Redis缓存热点数据
   - 多级缓存策略

2. **数据库优化**:
   - 使用MyBatis Plus提供的分页插件
   - 合理设计数据库索引
   - 避免N+1查询问题

3. **异步处理**:
   - 使用Spring AMQP处理耗时操作
   - 异步记录日志和统计信息

4. **请求优化**:
   - 实现接口访问频率限制，防止恶意请求
   - 合理设置HTTP缓存头

5. **代码优化**:
   - 使用Lombok简化代码，减少模板代码
   - 利用Hutool等工具类库提高开发效率

### 5. 异常处理机制

**问题**: 项目中的异常处理机制是如何设计的？

**答案**: 
1. **全局异常处理**:
   - 使用@ControllerAdvice和@ExceptionHandler实现全局异常捕获
   - 对不同类型的异常进行分类处理，返回统一格式的错误信息

2. **异常日志记录**:
   - 使用AOP技术在异常发生时自动记录详细的异常信息
   - 异常日志包含请求参数、异常堆栈、时间戳等信息

3. **自定义异常**:
   - 定义BizException等自定义异常类，用于业务异常处理
   - 异常包含错误码和错误信息，方便前端展示和问题定位

4. **异常响应标准化**:
   - 所有异常都返回标准化的JSON响应格式
   - 包含状态码、错误信息、时间戳等字段

### 6. 定时任务实现

**问题**: 项目中的定时任务是如何实现的？有哪些功能？

3. **应用场景**:
   - 定期清理缓存数据
   - 定时发布文章
   - 数据统计和报表生成

### 7. 接口设计规范

**问题**: 项目中的API接口是如何设计的？遵循哪些规范？

**答案**:

## 部署说明

### 环境要求
- JDK 1.8+
- MySQL 5.7+
- Redis 5.0+
- Node.js 14+
- Maven 3.6+

### 后端部署
1. 克隆项目
```bash
git clone https://github.com/yourusername/aurora.git
cd aurora/aurora-springboot
```

2. 导入数据库
- 执行 `sql/aurora.sql` 创建数据库和表结构

3. 配置数据库连接
- 修改 `application-dev.yml` 中的数据库连接信息

4. 打包运行
```bash
mvn clean package
java -jar target/aurora-springboot-0.0.1.jar
```

### 前端部署

#### 管理后台
```bash
cd aurora-vue/aurora-admin
npm install
npm run build
```

#### 博客前台
```bash
cd aurora-vue/aurora-blog
npm install
npm run build
```

项目提供了Dockerfile，支持容器化部署
